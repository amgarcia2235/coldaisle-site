Free tool

ipmitool and Redfish, for when it's already gone wrong.

The commands a technician reaches for during an outage. Run the setup once, then copy what you need. Options and paths differ by maker and firmware.

export BMC=10.0.8.15 BMC_USER=admin
read -rs IPMI_PASSWORD; export IPMI_PASSWORD

ipmi() { ipmitool -I lanplus -H "$BMC" -U "$BMC_USER" -E "$@"; }
rf()   { curl -sk -u "$BMC_USER:$IPMI_PASSWORD" -H 'Content-Type: application/json' "$@"; }

# Redfish paths differ by maker. List yours, then set these.
rf "https://$BMC/redfish/v1/Systems" | jq -r '.Members[]."@odata.id"'
SYS=/redfish/v1/Systems/1 CHS=/redfish/v1/Chassis/1 MGR=/redfish/v1/Managers/1 LOG=SEL

-E reads the password from IPMI_PASSWORD. curl -k skips the certificate check because BMCs usually have self-signed certificates, so keep this on your management network. Redfish lines need jq.

Is it on?

Chassis state and faults

ipmitool
ipmi chassis status
Redfish

Why did it last restart?

ipmitool
ipmi chassis restart_cause
RedfishNo direct equivalent

Which reset types does this BMC allow?

ipmitoolNo direct equivalent
Redfish
rf "https://$BMC$SYS" | jq '.Actions."#ComputerSystem.Reset"'

Power on

ipmitool
ipmi chassis power on
Redfish
rf -X POST "https://$BMC$SYS/Actions/ComputerSystem.Reset" -d '{"ResetType":"On"}'

Clean shutdown

Asks the OS to shut down. A hung OS will not answer.

Destructive

Stops every service on the host.

ipmitool
ipmi chassis power soft
Redfish
rf -X POST "https://$BMC$SYS/Actions/ComputerSystem.Reset" -d '{"ResetType":"GracefulShutdown"}'

Power cycle

Cuts power, waits, powers back on.

Destructive

Anything unsaved on the server is lost.

ipmitool
ipmi chassis power cycle
Redfish
rf -X POST "https://$BMC$SYS/Actions/ComputerSystem.Reset" -d '{"ResetType":"PowerCycle"}'

Hard reset

Restarts without cutting power.

Destructive

Anything unsaved on the server is lost.

ipmitool
ipmi chassis power reset
Redfish
rf -X POST "https://$BMC$SYS/Actions/ComputerSystem.Reset" -d '{"ResetType":"ForceRestart"}'

Force off

Stays off until someone powers it on.

Destructive

Anything unsaved on the server is lost.

ipmitool
ipmi chassis power off
Redfish
rf -X POST "https://$BMC$SYS/Actions/ComputerSystem.Reset" -d '{"ResetType":"ForceOff"}'

Event log

TaskipmitoolRedfish

How full is the log?

For Redfish, list the log services first. Some makers keep the log under $MGR instead of $SYS.

ipmitool
ipmi sel info
Redfish
rf "https://$BMC$SYS/LogServices" | jq -r '.Members[]."@odata.id"'

The last 30 events

Set LOG to the name your BMC gives its log service.

ipmitool
ipmi sel elist last 30
Redfish
rf "https://$BMC$SYS/LogServices/$LOG/Entries" | jq '.Members[] | {Created, Severity, Message}'

Save the whole log to a file

Do this before you clear anything.

ipmitool
ipmi sel elist > "sel-$BMC-$(date +%F).txt"
Redfish
rf "https://$BMC$SYS/LogServices/$LOG/Entries" > "sel-$BMC-$(date +%F).json"

One raw record, for the decoder

Record ID 1. Drop the first two bytes of the reply. Paste the rest into the decoder.

ipmitool
ipmi raw 0x0a 0x43 0x00 0x00 0x01 0x00 0x00 0xff
RedfishNo direct equivalent

Clear the log

Destructive

Cannot be undone. Save the log first.

ipmitool
ipmi sel clear
Redfish
rf -X POST "https://$BMC$SYS/LogServices/$LOG/Actions/LogService.ClearLog" -d '{}'

Identify light

TaskipmitoolRedfish

Blink for 60 seconds

Redfish keeps it on until you turn it off. Older firmware uses {"IndicatorLED":"Blinking"} instead.

ipmitool
ipmi chassis identify 60
Redfish
rf -X PATCH "https://$BMC$SYS" -d '{"LocationIndicatorActive":true}'

Turn it off

ipmitool
ipmi chassis identify 0
Redfish
rf -X PATCH "https://$BMC$SYS" -d '{"LocationIndicatorActive":false}'

Serial over LAN

TaskipmitoolRedfish

Open the console

End the session with ~. at the start of a line. Inside SSH, type ~~. instead.

ipmitool
ipmi sol activate
RedfishNo direct equivalent

Free a session someone left open

ipmitool
ipmi sol deactivate
RedfishNo direct equivalent

Read the serial settings

Redfish has no standard call for a serial session. Use ipmitool here.

ipmitool
ipmi sol info 1
RedfishNo direct equivalent

BMC network

TaskipmitoolRedfish

Read the network settings

LAN channel 1 is common, not universal.

ipmitool
ipmi lan print 1
Redfish
rf "https://$BMC$MGR/EthernetInterfaces" | jq -r '.Members[]."@odata.id"'

List BMC users

ipmitool
ipmi user list 1
Redfish
rf "https://$BMC/redfish/v1/AccountService/Accounts" | jq -r '.Members[]."@odata.id"'

Set a static address

Safer from the host itself: ipmitool -I open lan set 1 ...

Destructive

Over the network, this can cut you off from the BMC.

ipmitool
ipmi lan set 1 ipsrc static
ipmi lan set 1 ipaddr 10.0.8.20
ipmi lan set 1 netmask 255.255.255.0
ipmi lan set 1 defgw ipaddr 10.0.8.1
RedfishNo direct equivalent

Restart the BMC

The server keeps running. The BMC drops off the network while it restarts.

Destructive

You lose the BMC until it comes back.

ipmitool
ipmi mc reset cold
Redfish
rf -X POST "https://$BMC$MGR/Actions/Manager.Reset" -d '{"ResetType":"GracefulRestart"}'
