The server stopped answering.

Work down this list in order. Bookmark it now, or print it and keep it in the rack.

In the commands, ipmi means: ipmitool -I lanplus -H <bmc> -U <user> -E

ipmi = ipmitool -I lanplus -H <bmc> -U <user> -E

  1. Write down the box and the time

    Server name, BMC address, when it stopped answering, and what changed last.

  2. Rule out your own path

    From a second machine or network, ping the OS address and try SSH. Check its switch port.

  3. Reach the BMC

    Ping its address or open its web page, then ask it who it is. No answer? Go to the box at the end.

    ipmi mc info

  4. Read the power state

    Off is a finding. Do not power it on yet.

    ipmi chassis power status
ipmi chassis restart_cause

  5. Read the log before you touch anything

    Find the first event of the failure, not the last. Paste raw records into the decoder.

    ipmi sel elist last 30

    Thermal trip in the log? Do not just power it back on. Check that every fan turns and that the processor heatsink is seated.

  6. Check the sensors

    Temperatures, fans and power supplies against their limits.

    ipmi sdr type Temperature
ipmi sdr type Fan
ipmi sdr type "Power Supply"

  7. Look at the console

    Capture any crash text before you restart. End the session with ~. at the start of a line.

    ipmi sol activate

  8. Restart, gentlest first

    Confirm the name and address again. Try a clean shutdown; if the OS does not answer, power cycle.

    ipmi chassis power soft
ipmi chassis power cycle

    Destructive. Anything unsaved on the server is lost.

  9. Watch it come back, then write it up

    Check temperatures and fans once it is up. Save the log and fill in the ticket below.

    ipmi sel elist > sel-$(date +%F).txt

The BMC doesn't answer either

Check the power feed, the PDU and the BMC's network cable and switch port. If the OS is still up, restart the BMC from the host with ipmitool -I open mc reset cold. Otherwise this needs hands at the rack: send them the rack and unit position.
